# Troll Master

Projeto Node.js + Express. Todos os arquivos do site ficam na raiz para facilitar o envio pelo GitHub no celular.

## Publicar no Render
- Build Command: `npm install`
- Start Command: `npm start`
- Runtime: Node

O servidor cria as pastas `data` e `uploads` automaticamente. Configure armazenamento persistente no serviço de hospedagem para preservar cadastros e mídias entre reinicializações.

A importação por link lê apenas metadados públicos disponíveis na página. Sites que bloqueiam leitura automática podem não fornecer imagens ou vídeos.
